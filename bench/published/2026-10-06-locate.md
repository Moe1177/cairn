# Locate benchmark: grep, the code graph, or both (2026-10-06)

Offline: no agent runs, nothing is spent. `cairn bench-locate` asks each locator every question in
a suite's `locate.yaml` and scores where the first answer file lands (hit@k, MRR), the share of
answer files in the top five (recall@5), the size of the answer (~4 characters a token) and the
time taken (Windows 11, warm graph in memory, git grep per repo).

- **Questions:** 76, written from the code by separate agents that never ran a locator, and
  checked against the code before scoring. They come in five kinds:
  - *literal*: names an identifier, route or message;
  - *vocabulary*: describes behaviour in other words;
  - *chain*: who calls X, what breaks;
  - *broad*: a common word, one right file;
  - *cross-repo*: the answer is in another repo.
- **Dev split (40), used for tuning:** sockshop (9 repos, pinned) plus the fleetline and
  shopverse fixtures.
- **Held-out split (36), never tuned on:** supabase-js (6 repos, pinned) and networkx 3.4.2
  (pinned).
- **Code graphs:** graphify 0.9.77 `--code-only`.

**Read with care:** 4-8 questions per cell. Differences of one question move a cell by 0.12-0.25.

## Findings

1. **grep matched or beat the code graph on every kind of question, on both splits.** The one
   exception is the 4 held-out cross-repo questions. graphify's code graph holds functions and
   classes but not routes, constants or messages, and it ranks by symbol name. That makes it just
   as literal as grep.
2. **Neither locator solves vocabulary mismatch.** At hit@5, grep scored 0.12 on dev and 0.38 on
   held-out; the graph scored 0.00 and 0.12. Questions phrased in other words than the code need
   something that knows meaning, not names.
3. **The router as first planned lost to grep.** It sent broad, chain and wordy questions to the
   graph. At hit@5 it scored dev 0.57 against grep's 0.60, and held-out 0.64 against 0.67.
4. **The tuned router (decided on dev only) wins on hit@1 at the same cost.** It asks grep first
   and puts the defining file last for chain questions. The graph only names the symbol on hits
   it agrees with, and answers alone when grep finds nothing. Filling grep's empty places with
   graph hits was also tried on dev: it added no answers and 16% more tokens, so it was dropped.

| split | locator | hit@1 | hit@3 | hit@5 | MRR | tokens |
|---|---|---|---|---|---|---|
| dev | grep | 0.35 | 0.57 | 0.60 | 0.47 | 68 |
| dev | graph | 0.12 | 0.15 | 0.17 | 0.14 | 41 |
| dev | router as planned | 0.28 | 0.53 | 0.57 | 0.41 | 67 |
| dev | **hybrid (tuned)** | **0.45** | 0.57 | 0.60 | **0.52** | 68 |
| held | grep | 0.42 | 0.64 | 0.67 | 0.54 | 138 |
| held | graph | 0.22 | 0.36 | 0.39 | 0.29 | 166 |
| held | router as planned | 0.31 | 0.58 | 0.64 | 0.44 | 169 |
| held | **hybrid (tuned)** | **0.56** | 0.64 | 0.67 | **0.62** | 138 |

The whole hit@1 gain is chain questions: from 0.25 to 0.75 on dev, and from 0.00 to 0.62 on the
held-out split.
